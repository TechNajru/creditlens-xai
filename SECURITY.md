# Security policy

CreditLens XAI is an **educational prototype**, not a production financial system. It must not be used with real customer data.

## Reporting a vulnerability
Please open a private security advisory on the GitHub repository (Security tab -> "Report a vulnerability"), or email the maintainer.
Do not post exploit details in public issues. This is a student project: expect best-effort responses.

## What is and is not covered
See `docs/security_and_workflow.md` (controls that exist and do not exist) and `docs/security_review.md` (tools run and results).
Known limitations include: no MFA, no password reset, no IP rate limiting, no Content-Security-Policy, no encryption at rest.
